# LOY-Tournament
Streamlabs-ready FGC Tournament Overlay + Signup system for Tekken 8. Built for LOY Software (lambofyeshu.life). Realtime admin control, transparent OBS overlay, and public player registration.

## Admin panel
Gothic / satin-bow Tournament Control Panel lives at `/admin`. Socket.io events are unchanged (`adminUpdateMatch`, `incrementScore`, `resetScores`, `matchUpdate`, `signupsUpdate`). Overlay and signup pages are untouched.
