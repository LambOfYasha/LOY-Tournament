# Next.js Refactor Reminder — LOY-Tournament

## Tag
`[nextjs-refactor]`

Also recognized as: `[remind-nextjs]`, `[loy-nextjs]`
Also marked `[draft]` so mss-draft-reminder can surface it.

## Default state
**Parked / inactive.** Do not start the Next.js refactor unless the user types the tag in the current session.

## When the tag is present
1. Confirm the user wants the refactor to begin now.
2. Read https://github.com/LambOfYasha/LOY-Tournament and issue #1.
3. Refactor Express + static HTML + Socket.io into a proper Next.js app.
4. Preserve overlay, admin, and signup functionality first. Design later unless asked.
5. Keep domain and event-day hosting (Cloudflare Tunnel / VPS) in mind.

## When the tag is absent
Do nothing about the Next.js migration. The current Express app stays the working version.
